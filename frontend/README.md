# Firelytics AI Frontend

React + Vite frontend. Run `npm install`, copy `.env.example` to `.env`, then `npm run dev`.

Configure `VITE_API_BASE_URL=http://localhost:8000/api` to connect to the FastAPI service. If the backend is unavailable, the UI falls back to the bundled 11-record team-supplied inventory.

See the repository root README for architecture, API routes, provenance notes, and backend setup.
